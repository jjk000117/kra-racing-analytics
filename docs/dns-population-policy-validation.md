# DNS 모델링 모집단 정책 검증

검증일: 2026-08-02  
대상: DNS가 한 마리 이상 있는 완료·공식 연승 경주 605개

## 결론

DNS는 **말 단위로 제외**하고, DNS가 존재한다는 이유만으로 **경주 전체를 제외하지 않는다**.

605경주 모두 완료 상태, 7개 공식 승식, 1착과 공식 연승 결과를 갖고 있었다. DNS 1~2두 경주가
601개로 99.34%였고, DNS 3두인 4경주도 각각 유효 출전마 8두가 정상 완주했다. 경주 취소,
결과 미확정, 공식 승식 누락, 등록·결과 행 불일치와 연승 결과 이상은 0건이었다.

따라서 DNS는 정상적으로 시행된 경주 안의 비출전 말 상태로 해석할 수 있다. 모델링에서 해당
말의 적중 여부를 음성으로 만들지 않고 행 자체를 제외하되, 함께 출전한 다른 말과 경주는
보존한다.

주행정지 말이 있는 13경주도 모두 7개 공식 승식, 1착과 3개 연승 적중마를 갖고 있다. 이는
경주 전체 중단이 아니라 개별 출전마의 실제 출전 후 비완주다. 해당 말은 `is_valid_start=true`,
`is_valid_finish=false`인 음성 가능 행으로 보존한다.

## 확정 정책

### 말 단위 제외

다음을 만족하는 행은 모델링 Snapshot에서 제외한다.

- `result_status = 'DNS'`
- `is_valid_start = false`

DNS는 타깃 `0`으로 변환하지 않는다. 출전하지 않은 말을 실패 사례로 학습시키면 출전 가능성
예측과 연승 적중 예측이 섞이기 때문이다.

`RACE_STOPPED`와 `DISQUALIFIED`는 실제 출전이 확인된 상태이므로 말 행을 유지한다. 공식 연승
적중마가 아니면 `place_hit=0`이다.

### 경주 단위 제외

DNS 수 자체는 경주 제외 조건이 아니다. 다음 중 하나라도 발생해 경주 전체의 학습 계약이
깨질 때만 경주를 제외한다.

1. 경주 상태가 `COMPLETED`가 아님
2. 공식 연승 원문이 없거나 파싱되지 않음
3. 공식 연승 적중마가 출전마와 결합되지 않거나 중복 결합됨
4. 공식 적중마가 모델링 모집단에 존재하지 않음
5. DNS 외 `NON_STANDARD_UNRESOLVED`, `MISSING` 등 베팅 가능 여부가 미해결인 말이 존재
6. 결과 행 Grain·업무키 또는 경주 상태 무결성 검사 실패

제외 시 경주를 음성 사례로 바꾸지 않고 `population_exclusion_reason`을 기록한다.

### 민감도 집합

DNS 없는 3,977경주 집합은 주 모집단을 대체하지 않는다. DNS 경주 포함 여부에 따른 성능 차이를
확인하는 선택적 민감도 집합으로만 유지한다. 주 Snapshot에는 DNS 말만 제거한 4,582경주의
48,524개 valid-start 행을 사용한다.

## 영향

- 정상 시행된 605경주와 그 안의 5,892개 실제 출전 행을 잃지 않는다.
- DNS 659행을 잘못된 음성 타깃으로 학습하지 않는다.
- 모집단 차이로 인한 선택 편향을 줄인다.
- 실제 운영 시점의 사전 출전표가 필요하다는 6B 한계는 유지한다. 이번 정책은 과거 결과
  데이터로 개발 Snapshot을 구성하는 규칙이며 실시간 출전표 복원을 대신하지 않는다.
