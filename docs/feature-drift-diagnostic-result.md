# 2026-05~07 성능 저하 동반 분포 변화 진단

분석일: 2026-08-09  
분석 버전: `feature_drift_diagnostic_v1`  
상태: 진단 완료, 모델·Feature·Calibration 변경 없음

## 진단 질문과 비교 범위

- 안정기간: 2025-10-02~2026-04-26, 1,034경주·11,357행
- 저하기간: 2026-05-01~2026-07-26, 455경주·4,645행
- 경주 구조 Grain: 경주당 1행
- 말·관계자 Feature와 타깃 Grain: 출전마 행

기존 28개 모델 입력, Snapshot, baseline_v1과 walk-forward 결과를 변경하지 않고 입력 분포,
타깃 분포와 특정 경주군 구성 변화가 성능 저하와 함께 나타났는지만 비교한다. 인과효과나 새로운
모델 선택을 주장하지 않는다.

## 결론

가장 큰 변화는 **등록두수 구성**이다. 안정기간 경주의 31.62%였던 12두 경주는 저하기간 0.22%로
거의 사라졌고, 8~10두 경주는 16.45%에서 40.22%로 증가했다. 이에 따라 출전마 행 기준 평균
등록두수는 11.20두에서 10.50두로 감소했다.

PLC 양성률은 27.32%에서 29.36%로 `+2.04%p` 상승했다. 안정기간의 등록두수별 PLC 양성률을
저하기간 등록두수 구성에 적용하면 기대 양성률은 29.30%다. 즉 관측 상승분 약 `2.04%p` 중
약 `1.98%p`가 등록두수 구성 변화와 함께 설명되고, 등록두수별 비율 변화로 남는 차이는 약
`0.07%p`다. 이는 등록두수가 타깃 분포 변화의 주된 동반 요인이라는 강한 근거다.

그 밖에는 최근 5회 PLC 적중률 상위 분위가 낮아지고 최근 평균착순이 소폭 나빠졌다. 반면
경마장·등급·거리 구성 변화는 등록두수보다 작고, history availability와 기수·조교사 적중률은
대체로 안정적이다. 따라서 현재 증거는 다음을 지지한다.

1. **타깃 분포 변화:** 확인됨. PLC 양성률 `+2.04%p`.
2. **특정 경주군 구성 변화:** 강하게 확인됨. 12두 경주 급감과 8~10두 경주 증가.
3. **입력 분포 변화:** 일부 확인됨. 등록두수와 최근 폼, 시간 누적형 count가 변화.

등록두수 mix는 무정보 기준선까지 함께 악화된 현상과 일치한다. 그러나 walk-forward Logistic의
기준선 대비 개선폭 축소와 7월 calibration drift까지 전부 설명한다고 단정할 수는 없다. 현재
walk-forward 결과에는 행 단위 예측이 보존되지 않아 등록두수 고정 후 모델 손실을 직접 분해하지
않았기 때문이다.

## 판정

### 확인된 사실

- 작은 등록두수 경주가 크게 늘었고 12두 경주는 거의 사라졌다.
- 이 구성 변화와 함께 PLC 양성률이 약 2.04%p 상승했다.
- 등록두수별 양성률은 거의 변하지 않아 타깃 상승의 대부분이 mix 변화와 일치한다.
- 최근 5회 성적 분포는 상위 분위 적중률과 평균착순에서 소폭 악화됐다.
- history availability, 관계자 적중률, 경마장 구성은 대체로 안정적이다.

### 가능성이 높은 설명

- 저하기간의 높은 기본 양성률과 무정보 기준선 손실 상승에는 등록두수 mix 변화가 크게 관련된다.
- 최근 폼 분포의 소폭 악화는 Logistic이 과거 비율 Feature를 사용하는 방식의 시간 안정성을 일부
  약화했을 가능성이 있다.

### 현재 확인할 수 없는 것

- 등록두수 mix를 고정했을 때 Logistic 손실 증가가 얼마나 남는지
- 특정 등급·거리 안에서 모델 calibration이 악화됐는지
- 일정·계절·운영 변화가 등록두수 감소를 유발했는지

이 세 항목은 행 단위 walk-forward 예측을 저장하지 않은 현재 결과만으로는 직접 계산할 수 없다.
이번 진단에서는 금지된 재학습이나 모델 변경으로 이를 보완하지 않는다.

전체 28개 Feature의 평균·P10/P25/P50/P75/P90·NULL률과 모든 범주 비중은 로컬
`data/exports/modeling/feature_drift_diagnostic_v1/feature_drift_result.json`에 보존한다.
