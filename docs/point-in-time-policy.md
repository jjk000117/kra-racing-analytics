# Point-in-Time 및 데이터 누수 방지 정책

## 핵심 계약

모든 이력 기반 분석 행은 다음을 만족해야 한다.

```text
source_max_event_date < feature_as_of
```

현재 경주일과 같은 날짜의 기록도 과거 이력으로 사용하지 않는다.

## 제외 정보

- 현재 경주 결과와 경주기록
- 동일 날짜의 결과
- 미래 결과
- 현재 경주의 배당, 매출, 환급, 확정배당
- 사후에만 공개되는 정보
- 가용시점이 `UNKNOWN`인 후보 지표

## 이력 계산

- 경주일보다 엄격히 이전인 이벤트만 조인한다.
- Last-3, Last-5 전에 이력을 시간순으로 정렬한다.
- 3개월·6개월은 실제 달력 경계를 사용한다.
- `history_complete`로 이력 없음과 원천 범위 불완전을 구분한다.
- 말, 기수, 조교사와 이들의 조합에 동일한 시간 제약을 적용한다.

## 모델 및 Power BI 경계

- Power BI는 승인된 Canonical/Mart만 조회한다.
- 향후 모델은 승인된 Feature Snapshot만 읽는다.
- Sales와 확정배당은 사후 시장·정산 분석에만 사용한다.
- 시간 기반 모델 평가에서는 한 경주의 행을 여러 데이터 분할로 나누지 않는다.
- Final Test는 모델 또는 의사결정 규칙 선택에 사용하지 않는다.

## 자동 검사

후속 구현은 최소한 다음 위반을 실패로 처리해야 한다.

- 현재 이벤트가 자기 이력에 포함됨
- 이력 이벤트 날짜가 `feature_as_of` 이상임
- 이력이 시간순으로 정렬되지 않음
- 사후 Sales/Dividend 컬럼이 사전 분석 데이터셋에 존재함
- 가용시점이 승인되지 않은 지표가 Mart 또는 Feature Snapshot에 포함됨
