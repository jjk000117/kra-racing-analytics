## 저장 및 감사 방식

응답 본문은 `data/raw/api4_3/{year}/meet_{meet}/` 아래에 생성 전용 모드로 저장한다. 같은 경로의 기존 파일은 덮어쓰지 않는다. DuckDB의 `raw.collection_batch`, `raw.api_request`, `raw.raw_file`은 배치·요청·파일을 연결하고 상태, 수집 건수, 상대 경로, 바이트 크기, SHA256을 보존한다.

감사 명령은 다음을 다시 확인한다.

- 배치에 기록된 요청 수와 실제 요청 행 수의 일치
- Manifest URL의 `ServiceKey=REDACTED` 처리
- Raw 파일 존재 여부
- Raw 파일 크기와 Manifest 값의 일치
- Raw 파일 SHA256 재계산 결과의 일치

Raw 파일과 로컬 DuckDB는 Git 추적 대상이 아니다. API 키는 기존 로컬 환경에서 실행 프로세스로만 읽으며 저장소 파일로 복사하지 않는다.
