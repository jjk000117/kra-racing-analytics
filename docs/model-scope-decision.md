# 5G 첫 모델과 복승 후속 방향 결정

결정일: 2026-08-02

## 결정

첫 완성 모델은 **연승식 적중 여부를 타깃으로 하는 말 단위 확률모델**로 한다.

- 예측 Grain: `경주 × 출전마`
- 타깃: 해당 출전마가 공식 연승 적중마인지 여부
- 출력: 출전마별 연승 적중확률
- 첫 모델의 목적: Feature 파이프라인, 날짜순 검증, 확률평가와 Calibration 구조 완성

첫 모델은 즉시 수익성을 입증하는 최종 베팅모델이 아니다. Point-in-Time Feature를 안전하게
구성하고 미래 경주에 대해 확률을 생성·검증하는 전체 모델링 절차를 완성하는 기준 모델이다.

## 복승식 후속 방향

복승식은 핵심 후속 목표로 유지한다. 첫 구현 방식은 **경주 내 두 마리 조합 직접 분류**를
기본안으로 둔다.

- 예측 Grain: `경주 × 비순서 2두 조합`
- 타깃: 해당 조합이 공식 복승 적중 조합인지 여부
- 출력: 조합별 복승 적중확률
- 기본 Feature: 두 말의 개별 Feature, 차이·합계·상호작용과 경주 전체 경쟁구조

연승 모델의 출력확률을 복승 확률로 자동 변환하지 않는다. 말별 연승 주변확률만으로 두 말이
동시에 1·2위에 드는 공동확률을 식별할 수 없기 때문이다.

연승 단계에서 복승 단계로 재사용하는 범위는 다음으로 제한한다.

- Point-in-Time Feature와 원천 데이터 파이프라인
- 경주·출전마 식별자와 날짜순 데이터 분할
- 누수 검사와 시간순 검증 구조
- 확률평가, Calibration과 모델 결과 관리 방식

## 복승 고도화 후보

조합 직접 분류 기준모델을 만든 뒤 다음 방식을 비교할 수 있다.

1. **별도 결합모델**: 시간순 Out-of-Fold 말별 예측과 조합 Feature를 결합
2. **순위 기반 공동확률 모델**: 경주 전체 순위분포에서 비순서 1·2위 공동확률 계산

두 방식은 복승 기본모델 이전의 필수 구현이 아니며 현재 범위에서는 설계 후보로만 유지한다.

## 현재 범위에서 하지 않는 작업

- 모델 학습과 Hyperparameter 탐색
- 추가 KRA API 호출
- 연승 확률을 복승 확률로 변환하는 임의 공식
- 배당을 모델 Feature에 포함하는 작업
- 복승 결합모델이나 순위모델 구현

## 다음 데이터 설계 단계

다음 단계는 **6A 연승 모델링 데이터 계약 설계**다. 아직 데이터를 수집하거나 모델을 학습하지
않고 다음 항목을 확정한다.

1. 모델링 모집단과 제외 조건
2. `경주 × 출전마` 업무키와 연승 타깃 생성 규칙
3. 예측 기준시각과 Feature별 Point-in-Time 허용 조건
4. 기존 데이터로 만들 수 있는 Feature와 추가 API가 필요한 Feature의 구분
5. 날짜순 Train·Validation·Test 구간
6. Log Loss, Brier Score와 Calibration 중심의 평가 계약
7. 복승식 조합 직접 분류에서 재사용할 데이터 구조의 경계

6A 결과가 승인된 뒤에만 필요한 추가 API 범위와 구현 순서를 결정한다.
