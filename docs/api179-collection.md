## 데이터 경계

API179_1의 매출과 확정배당은 경주 후 생성되는 정보다. 시장 분석과 사후 베팅 평가에는 사용할 수 있지만 예측 시점 Feature에는 사용할 수 없다. 이후 Canonical Sales Dataset은 `race_date + meet_code + race_no + pool`을 업무 키로 검토하며, 경주 수준 결합은 `race_date + meet_code + race_no`를 사용한다.

응답 원본은 `data/raw/api179_1/{year}/meet_{meet}/`에 생성 전용으로 저장한다. 배치 감사는 요청 수, 키 마스킹, 파일 존재, 크기 및 SHA256을 재검산한다. Raw와 DuckDB는 Git에서 제외된다.

## API 키 관리

실제 키는 Git에서 제외된 프로젝트 루트 `.env`의 `KRA_API_KEY`로 관리한다. 저장소에는 값이 없는 `.env.example`만 추적한다. 프로그램은 Manifest URL에 `ServiceKey=REDACTED`만 기록한다.
