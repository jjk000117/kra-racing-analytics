# 5D 시장 구조 분석 결과

## 분석 질문

정상 완료되고 7개 공식 승식 매출이 모두 존재하는 경주를 기준으로 다음을 확인했다.

1. 월별 차이가 분석 범위를 제한할 정도로 큰가?
2. 서울과 부산경남을 분리해야 하는가?
3. 특정 등급을 제외해야 하는가?
4. 매출 구조만으로 모델 대상 승식을 선택할 수 있는가?

재현 가능한 전체 분석과 차트는 `notebooks/05d_market_structure_analysis.ipynb`에 저장했다.

## 분석 모집단

- 기간: 2024-01-05~2026-07-26
- 시장 적격 경주: 4,582건
- 경주 × 승식 행: 32,074건
- 승식: 공식 7개
- API 수집 매출 합계: 13,098,987,380,400원

취소·결과 미확정·매출 없는 경주는 Fact에 보존하되 이 분석에서는 제외했다.

## 월별 분석

- 관측 월: 31개월
- 월별 경주 수: 108~180경주
- 월별 경주당 평균 매출: 25.27억~32.12억원
- 월별 경주당 평균 매출 변동계수: 약 5%

월별 총매출 차이는 경주 수 변화의 영향을 크게 받는다. 경주당 매출의 월간 변동은 존재하지만
특정 월을 시장 분석에서 일괄 제외할 정도의 구조적 단절로 보기는 어렵다. 월은 제외 조건이
아니라 추세와 이상치를 확인하는 분석 차원으로 유지한다.

## 경마장 분석

| 경마장 | 경주 수 | 경주 비중 | 매출 비중 | 경주당 평균 매출 | 경주당 중앙값 매출 |
|---|---:|---:|---:|---:|---:|
| 서울 | 2,698 | 58.9% | 62.5% | 30.34억원 | 30.38억원 |
| 부산경남 | 1,884 | 41.1% | 37.5% | 26.08억원 | 24.11억원 |

서울의 경주당 평균 매출은 부산경남보다 약 16%, 중앙값은 약 26% 높다. 차이는 분석에서
통제해야 하지만 두 지역 모두 충분한 경주가 있고, 동일 승식의 지역별 매출 비중 차이는 최대
0.93%p에 그친다. 따라서 두 경마장을 모두 사용하고 `meet`를 비교·통제 차원으로 유지한다.

## 등급 분석

- 국5등급: 1,178경주
- 국6등급: 1,248경주
- 두 등급 합계: 전체 시장 적격 경주의 약 52.9%
- 등급별 경주당 평균 매출 범위: 21.95억~40.08억원
- 가장 높은 값: 1등급 40.08억원
- 가장 낮은 값: 국6등급 21.95억원

경주 수가 많은 등급과 경주당 매출이 높은 등급이 일치하지 않는다. 이는 등급을 미리
제외할 근거가 아니라 등급별 규모와 강도를 따로 비교해야 한다는 근거다. 10개 등급을 모두
유지한다.

## 승식별 시장 구성

| 승식 | 매출 비중 | 경주당 평균 매출 |
|---|---:|---:|
| 단승식 | 1.2% | 0.33억원 |
| 연승식 | 1.7% | 0.50억원 |
| 복승식 | 31.5% | 8.99억원 |
| 쌍승식 | 9.6% | 2.75억원 |
| 복연승식 | 4.2% | 1.20억원 |
| 삼복승식 | 34.2% | 9.78억원 |
| 삼쌍승식 | 17.6% | 5.04억원 |

삼복승식과 복승식에 매출이 집중되지만 매출은 시장 규모만 나타낸다. 적중 난도, 공식
적중배당, 모델의 예측 가능성 또는 실제 수익성을 나타내지 않는다. 따라서 이 결과만으로
승식을 선정하지 않는다.

## 범위 결정

- 날짜: 전체 기간 사용, 월은 추세 확인 차원으로 유지
- 경마장: 서울·부산경남 모두 사용, 지역 차원으로 통제
- 등급: 10개 전체 사용
- 승식: 7개 전체 보존, 아직 모델 후보를 확정하지 않음

연승식과 복승식은 사용자 관심 후보로 남아 있지만 분석 결과에 미리 반영하지 않는다.
