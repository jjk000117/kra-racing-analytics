# 연승 Logistic 월별 Walk-forward 시간 안정성 진단

실행일: 2026-08-09  
분석 버전: `walk_forward_stability_v1`  
상태: 10개 Fold 완료, baseline_v1·Final Test 산출물 변경 없음

## 목적과 경계

현재 28개 Feature와 raw Logistic 절차의 시간 안정성만 진단한다. Feature 선택, 모델 선택,
Calibration 추가와 새로운 최종 성능 주장은 수행하지 않는다.

- 최초 Fold는 baseline_v1과 동일한 최초 모델 학습기간 2024-10~2025-09를 사용한다.
- Feature 이력 계산에는 Snapshot에 반영된 기존 Warm-up 2024-01~09 데이터가 그대로 사용된다.
- 이후 Fold는 과거 전체 학습창을 한 달씩 확장하고 바로 다음 한 달을 평가한다.
- 전처리·28개 입력·L2 Logistic `C=1.0`, `class_weight=None`, `solver=lbfgs`를 유지한다.
- Calibration은 적용하지 않고 intercept/slope를 월별 진단값으로만 계산한다.
- 3개월 이동평균은 추세 확정 기준이 아니라 보조 진단으로만 사용한다.

## 결론

2025-10~2026-04는 월별 macro Log Loss가 `0.507~0.521` 범위로 비교적 안정적이었다. 2026-05,
06, 07에는 `0.533 → 0.551 → 0.570`으로 세 달 연속 상승해 후반부 저하가 단일 월의 일시적
변동만은 아닐 가능성을 보여준다. 같은 기간 3개월 보조 이동평균도 `0.522 → 0.533 → 0.551`로
상승했다. 단, 이동평균 자체를 추세 확정 규칙으로 사용하지 않는다.

모든 10개 월에서 Logistic은 월별 학습창 양성률 무정보 기준선보다 macro Log Loss와 Brier가
낮았다. 따라서 성능 저하에도 Feature 기반 확률모델의 우위는 유지됐다. 7월에는 calibration
intercept `-0.252`, slope `0.768`과 평균 예측 `0.313` 대비 실제 적중률 `0.296`이 함께 나타나
과대예측·확률 분산 과다 방향의 drift가 관찰됐다.

이 결과는 시간 안정성 진단이며 baseline_v1이나 기존 Final Test 결과를 수정하거나 사후 튜닝하는
근거로 사용하지 않는다.

원인은 이번 분석에서 확정하지 않는다.

## Calibration drift

- 2025-10~12 slope는 `1.207 → 1.135 → 1.095`로 1에 접근했다.
- 2026-01~05는 대체로 `0.988~1.067` 범위로 안정적이었다.
- 2026-06 slope는 `0.944`, 07월은 `0.768`로 낮아졌다.
- 7월 평균 예측확률이 실제 적중률보다 약 `0.0173` 높았다.

각 월의 5분위 calibration table은 로컬 결과 JSON에 모두 보존한다. 월별 표본은 1,230~1,921행이며
단일 월 intercept/slope의 작은 차이를 독립적인 구조 변화로 과대 해석하지 않는다.

- 모든 Fold 수렴

- `baseline_artifacts_modified = false`
