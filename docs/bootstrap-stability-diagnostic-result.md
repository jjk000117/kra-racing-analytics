# 경주 단위 Bootstrap 안정성 진단 결과

## 목적과 범위

2025-10~2026-04 안정기간의 경주 수준 손실에서 기대되는 표본 변동과 비교해,
2026-05~07 walk-forward 성능 저하 자체가 얼마나 이례적인지 진단했다. 기존 baseline_v1,
Final Test, walk-forward 및 Feature drift 결과는 변경하지 않았다.

## 방법

- 모집단: 안정기간 7개 walk-forward fold의 1,034경주
- 단위: 경주 단위 복원추출(행 단위 추출 미사용)
- 표본 크기: 5월 175경주, 6월 140경주, 7월 140경주
- 반복/seed: 10,000회, `20260809`
- 지표: 경주별 평균 손실을 다시 평균한 Macro Log Loss와 Macro Brier
- 관찰값: 기존 `walk_forward_result.json`의 값을 그대로 사용
- 3개월: 세 월의 실제 표본 크기를 각각 유지해 추출한 뒤 월별 Macro의 동일가중 평균

기존 결과에 경주별 손실이 없어 안정기간 7개 fold만 동일한 고정 Logistic 절차로 재현했다.
각 fold의 경주 수와 두 Macro 지표는 기존 결과와 절대오차 0으로 일치한 경우에만 bootstrap을
실행했다.

## 판단

- 5월은 안정기간의 흔한 중심 변동은 아니다. 두 지표 모두 P97.5를 넘었지만, bootstrap에서
  같거나 나쁜 표본이 각각 1.20%, 0.70% 존재해 6~7월보다는 덜 극단적이다.
- 6월과 7월은 두 지표 모두 안정기간 bootstrap P97.5를 크게 넘었고 10,000회 중 같거나
  나쁜 표본이 없었다.
- 3개월 평균도 두 지표 모두 동일했다. 따라서 관찰된 후반부 저하 전체를 안정기간 경주
  표본 변동만으로 충분히 설명하기는 어렵다.
- 사용자가 제시한 유형 중에는 **B에 가장 가깝다**. 다만 5월도 엄밀히는 흔한 수준이 아니라
  상단 꼬리에 위치한다.
- 다음 판단은 baseline drift 진단을 종료하기보다, 이미 확인된 등록두수 구성 변화를 출발점으로
  `registered_runner_count` 조건부 손실 분석을 진행하는 쪽이다. 이 분석은 이번 범위에 포함하지 않았다.

## 한계

- 안정기간은 7개월뿐이며 장기 기준분포가 아니다.
- 월별 경주 구성은 동일하지 않다.
- pooled bootstrap은 시간 순서, 연속성, 자기상관과 반복 출전 개체를 반영하지 않는다.
- expanding walk-forward에서 매월 학습 모델도 업데이트되므로 동일 모델 손실만 비교한 것이 아니다.
- 이 결과는 안정기간 경주 수준 손실의 표본 변동과 비교한 진단이며, drift의 존재나 원인을
  통계적으로 증명하지 않는다.

## 범위 준수와 검증

- Feature·모델·하이퍼파라미터·Calibration 변경 없음
- Final Test 재평가 없음
- 조건부 등록두수 분석 및 추가 Feature drift 분석 없음
- 보호 산출물 5개의 실행 전후 SHA256 동일
- 안정기간 7개 fold 기존 Macro 지표 재현 절대오차 0
- seed 고정 재현성, 경주 단위 Macro 계산, `>= 실제값` tail 정의 단위 테스트 완료
